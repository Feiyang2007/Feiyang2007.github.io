MuJoCo 强化学习（从零实现）

2026.10 — 规划中●纯 PyTorch · 不依赖现成 RL 库

不依赖 Stable-Baselines3 或 Ray RLlib，纯 PyTorch 手写 DQN 与 PPO， 在 MuJoCo 仿真环境（CartPole / Pendulum / HalfCheetah）中训练连续控制策略。 这是具身智能"大脑侧"的核心练习——从 hello world 到真能训出一个策略。

可交互 CartPole — 你自己当 RL Agent

存活步数：0 ← → 方向键控制小车 · 杆保持竖直不掉下来就算成功
↑ 这是 CartPole 环境——RL 入门 benchmark。AI 要做的就是自动学会这个控制。你手动玩几下，就知道为什么 RL 难了。
↑ 典型 RL 训练曲线示意（CartPole，每 episode 的累计回报随训练上升）· 真实训练曲线待跑出后替换

为什么从零写

调库谁都会，但 RL 的核心坑——回报稀疏、信用分配、探索与利用—— 只有自己写一遍才能真正理解。我计划先写 DQN（离散动作），再写 PPO（连续动作）。

环境顺序：CartPole（入门）→ Pendulum（连续控制）→ HalfCheetah（复杂 locomotion）。 每一步都画训练曲线、记录失败原因，沉淀成笔记。
